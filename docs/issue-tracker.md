# Issue tracker: Local Markdown

This workspace *is* the tracker. Issues and the spec live as markdown at the repo root (not under `.scratch/`).

## Wayfinding operations

- **Map**: `map.md`
- **Child ticket**: `issues/NN-<slug>.md`
- **Research write-up**: `research/NN-<slug>.md` (linked from the ticket, not pasted onto the map)
- **Spec**: `spec.md` (this map’s destination)
- **Blocking**: `Blocked by: NN, NN`
- **Claim**: `Status: claimed`
- **Resolve**: `## Answer` + `Status: resolved`, then gist into the map’s Decisions so far

Refer to tickets by **name**, not bare numbers.
